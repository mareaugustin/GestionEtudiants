# Gestion des Étudiants - Application Java Swing

Une application desktop Java avec interface Swing pour la gestion des étudiants (CRUD : Create, Read, Update, Delete).

## Fonctionnalités

- **Ajouter** un nouvel étudiant
- **Modifier** les informations d'un étudiant existant
- **Supprimer** un étudiant
- **Afficher** la liste des étudiants
- Interface utilisateur intuitive avec Java Swing

## Technologies utilisées

- Java 17+
- Java Swing pour l'interface graphique
- JDBC, MySQL

## Prérequis

- JDK 17 ou supérieur installé
- [Optionnel: Maven/Gradle installé si le projet utilise un système de build]
- [Optionnel: SGBD installé si utilisation d'une base de données]
